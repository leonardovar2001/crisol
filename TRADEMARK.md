# El nombre "Crisol"

La [licencia AGPL-3.0](LICENSE) cubre el **código**. No cubre el **nombre** ni el logo, y a propósito.

## Qué podés hacer sin permiso

- Correr Crisol, modificarlo y distribuir tus modificaciones, como dice la licencia.
- Decir que tu producto o servicio **"usa Crisol"**, **"está basado en Crisol"** o **"es compatible con Crisol"**.
- Usar el nombre para referirte al proyecto: artículos, charlas, documentación, comparativas.
- Correr una instancia y darle el nombre que quieras.

## Qué necesita permiso

- Llamar **"Crisol"** a un fork modificado, o usar un nombre lo bastante parecido como para confundir.
- Usar el nombre o el logo de manera que sugiera que el proyecto original respalda, mantiene o certifica lo tuyo.

Si tenés dudas sobre un uso concreto, abrí un issue. La respuesta por defecto es que sí.
